# Storm Reply Project

This repository serves as a template to get started with Storm Reply projects. It tries as best as possible to enforce best practices and propose a project organization based on previous projects.

Contribution guide is available [here](CONTRIBUTING.md).

Since this repository is aimed to be used for new projects within Storm Reply FR, do not hesitate as time passes to make propositions that ensure we are always up to date regarding the technologies we use and standards we follow.
